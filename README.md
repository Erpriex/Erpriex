<h1 align="center">Hello 👋, moi c'est Clément !</h1>

### 🚀 À propos

Développeur full stack, je bosse sur des applications web et mobiles en production, de la conception jusqu’au déploiement.

Je m’intéresse autant à l’expérience utilisateur qu’à l’architecture backend et à l’infrastructure. Mon objectif est simple : construire des produits fiables, performants et qui tiennent dans le temps.

### 💻 Ce que je fais

- Applications web (React, Next.js)
- APIs et backends (Node.js, Java, Spring Boot)
- Applications mobiles (React Native)
- Infrastructure et déploiement (Docker, AWS, GCP)
- Optimisation, maintenance et montée en charge

### ⚙️ Ma façon de travailler

- Code propre, lisible et maintenable
- Approche pragmatique, orientée solution
- Vision produit, pas juste technique
